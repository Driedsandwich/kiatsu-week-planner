# 気圧と周期の週予定（ハッカソン試作）

体調の波（気圧の変わり目と周期の時期）に合わせて、重い予定をずらす案を出す 1 枚の画面と、AI エージェント向けの MCP の口。
医療の判断ではありません。点は「予定を組み替える目安」で、体調への効果をうたう物ではありません。

## 中身
| 物 | 役 |
|---|---|
| `app/index.html` | 画面 1 枚（外の読み込み無し・`file://` で開ける）。`app/engine.js` の同じ中身を埋め込んである |
| `app/engine.js` | 計算だけの部品（画面と MCP が共有・依存なし） |
| `build.mjs` | `engine.js` を `index.html` の印（`ENGINE:BEGIN`／`END`）の間へ埋め込む。`node build.mjs` |
| `mcp/server.mjs`・`mcp/README.md` | MCP（stdio）。道具は `plan_week`・`phase_of` |
| `app/llms.txt` | AI 向けの短い説明 |
| `test/test.mjs` | 計算・MCP・埋め込みの一致の検査（`node test/test.mjs`） |
| `test/shot.mjs` | 画面の撮影と横はみ出しの測定（`node test/shot.mjs <出力フォルダ> <作業用プロファイル>`） |
| `shots/` | 撮った絵 |

## 使い方
`app/index.html` をブラウザで開く。`http(s)` で開くと気圧の予報を自動で読む。`file://` では最初は見本の気圧（作り物）で動く。「実際の予報を読む」の釦で試せる。`?sample=1` を付けると常に見本。

## 式と重み
日ごとの点 = 気圧の点 + 周期の点。

- 気圧の点: 「前日からの下げ幅」で数える。下げ幅 = 前日の日平均 − その日の日平均（hPa・日平均は 1 時間ごとの値の平均）。前日の値が無い日は不明（0 にはせず、行き先の候補にもしない）。
  2 hPa 未満 = 0／2 以上 = 1／4 以上 = 2／6 以上（強め）= 3。
- 周期の点: 周期の日数を L（21〜45・既定 28）として、月経 1〜5 日目／卵胞期 6〜(L−15) 日目／排卵のころ (L−14)〜(L−12) 日目／黄体期 それ以降。
  月経 1〜2 日目 = 2・月経 3〜5 日目 = 1・黄体期の後半（最後の 7 日）= 2・ほか 0。時期の区切りは、一般に言われる目安をそのまま置いた物で、個人差は見ていない。
- 札: 重さが「重い」の予定が、点 3 以上の日にあるとき「ずらす案」の札を付ける。気圧だけなら 6 hPa 以上、周期だけ（最大 2 点）では付かない。
- 行き先: 同じ週で、下げ幅が分かり・過ぎていない（`today` を渡したとき）・点が元の日より低く 3 未満の日。
  並び順は「点 + その日にもう決まった重い予定の数」が小さい順 → 同じ時刻の予定が無い日 → 元の日に近い日。候補が無ければ行き先なし（理由の文に書く）。
- 点の重みと閾値は試作の仮置きで、根拠を足していない。変える所は `engine.js` の `pressurePoints`・`phaseOf`・`HIGH_THRESHOLD`。

## データ・記録
- 気圧: Open-Meteo の予報 API（`models=jma_seamless`・`hourly=surface_pressure`・`timezone=Asia/Tokyo`・`forecast_days=7`・今週の月曜から見るため `past_days=6`）。鍵は要らない。出典の表示は画面の下。
- 周期と予定の記録は、この端末のブラウザ（localStorage）だけ。外へ送らない。MCP もネットへ出ない。
- 見本の予定・見本の周期・見本の気圧は作り物（画面にも「作り物」と出る）。

## 既知の限り
- 日平均の下げ幅しか見ていない（1 日の中の急な変化は見ない）。
- 予定は毎週同じ曜日の繰り返しだけ（特定の日の予定は未対応。MCP の `events[].date` では 1 回だけの予定を渡せる）。
- 予報は今日から 7 日先まで。それより先の週は気圧なしで表示する。
- スマホ幅（860px 以下）では、折れ線 → 周期の帯 → 日ごとの縦並びの順に並べ替える。
